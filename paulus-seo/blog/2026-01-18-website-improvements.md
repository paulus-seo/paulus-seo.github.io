안녕하세요! 어제에 이어 오늘도 웹사이트 사용성 개선을 위해 몇 가지 업데이트를 진행했습니다.
이번 업데이트는 주로 방문자 경험(UX)과 인터페이스(UI)를 개선하는 데 초점을 맞췄습니다.

<!-- truncate -->

**주요 개선 내용:**

1.  **포트폴리오 드롭다운 메뉴 적용**:
    상단 네비게이션의 `About`, `Projects`, `Awards` 링크를 `Portfolio`라는 하나의 드롭다운 메뉴로 통합했습니다. 이를 통해 네비게이션 바가 더 깔끔해졌고, 관련 페이지들을 논리적으로 그룹화하여 접근성을 높였습니다.

2.  **프로젝트 페이지 카드 디자인 개선**:
    `Projects` 페이지의 카드 레이아웃과 이미지 표시 방식을 대폭 개선하여 시각적 일관성과 안정감을 주었습니다.
    *   **일관된 카드 비율**: 각 프로젝트 카드의 이미지 영역과 하단의 제목/설명 영역이 항상 동일한 비율을 유지하도록 수정했습니다. 이제 이미지 크기에 따라 카드 전체 구조가 흔들리지 않습니다.
    *   **이미지 스타일링 개선**: 이미지가 잘리지 않고 원본 가로세로 비율을 유지하면서, 카드 영역 내에서 중앙에 위치하도록 변경했습니다. 이로 인해 크기가 작은 이미지도 어색함 없이 자연스럽게 보입니다.

3.  **Awards 페이지 캐러셀 기능 추가**:
    `Awards` 페이지를 대대적으로 개편하여 하나의 수상 내역에 여러 사진을 보여줄 수 있는 이미지 캐러셀을 도입했습니다.
    *   **다중 이미지 지원**: 이제 하나의 카드에 여러 장의 사진을 포함하고 넘겨볼 수 있습니다.
    *   **인터랙티브 UI**: 마우스를 올리면 나타나는 좌우 탐색 버튼과 하단의 인디케이터(점)를 통해 직관적으로 이미지를 탐색할 수 있습니다.
    *   **자동 재생 기능**: 사용자가 별도로 조작하지 않아도 일정 시간마다 사진이 자동으로 전환되어 동적인 느낌을 줍니다.
    *   **디자인 개선**: 이미지 모서리를 둥글게 처리하여 전체적인 디자인과 조화를 이루도록 하고, 부드러운 인상을 주도록 개선했습니다.

이번 개선 작업들을 통해 웹사이트를 둘러보는 경험이 더 쾌적해졌기를 바랍니다. 앞으로도 사용성과 디자인을 꾸준히 다듬어 나가겠습니다.

감사합니다!
